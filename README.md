# college-budget-web

## 1. 프로젝트 소개

대학생이 자신의 월수입, 목표 저축, 고정지출, 이월금, 지출 기록을 바탕으로 오늘 소비 가능한 금액을 확인하고 소비 가능 여부를 판단할 수 있도록 돕는 React 기반 지출 관리 웹 애플리케이션이다.

## 2. 프로젝트 목표

- 단순히 지출을 기록하는 것이 아니라, 지금 소비해도 되는지 판단하는 데 초점을 둔다.
- 오늘 사용 가능 금액을 직관적으로 확인할 수 있도록 구성한다.
- 예산 설정, 지출 기록, 분석, 캘린더를 통해 소비 흐름을 한눈에 파악할 수 있게 한다.
- 복잡한 금융 서비스가 아니라 대학생 생활비 관리에 맞춘 간단한 웹앱을 지향한다.

## 3. 주요 기능

### 3.1 홈

- 오늘 사용 가능 금액과 상태를 보여준다.
- 안전 / 주의 / 위험 / 초과 4단계로 현재 상태를 표시한다.
- 기준 날짜를 임시로 선택해 해당 날짜 기준의 예산 상태를 확인할 수 있다.

### 3.2 예산 설정

- 월수입, 목표 저축, 비상금, 고정지출, 이월금을 설정할 수 있다.
- 월별 예산 스냅샷을 관리한다.
- 직접 입력 방식과 근무 조건 계산 방식을 지원한다.
- 근무 조건 계산 시 3.3% 공제를 반영한다.
- 목표 계획 목록을 카드 형태로 관리한다.

### 3.3 지출 기록

- 일반 지출을 등록, 수정, 삭제할 수 있다.
- 정기지출을 별도로 관리할 수 있다.
- 최근 기록을 활용해 빠르게 입력할 수 있다.
- 지출 입력 중에도 소비 가능 여부를 미리 확인할 수 있다.

### 3.4 분석 리포트

- 월별 총 지출을 확인할 수 있다.
- 카테고리 비중과 전월 대비 변화를 볼 수 있다.
- 절약 팁과 소비 흐름을 함께 확인할 수 있다.

### 3.5 캘린더

- 날짜별 지출을 확인할 수 있다.
- 하루 기준 소득과 실제 지출을 구분해서 볼 수 있다.
- 선택한 날짜 기준으로 지출 흐름을 확인할 수 있다.

### 3.6 로그인 / 회원가입

- mock auth 기반 로그인과 회원가입을 지원한다.
- 계정별로 데이터를 분리해 관리한다.

### 3.7 마이페이지

- 사용자 정보를 확인할 수 있다.
- 예산 요약을 볼 수 있다.
- 데이터 초기화와 로그아웃을 제공한다.

## 5. 페이지 구조

Hash Router 기준 경로는 다음과 같다.

- `/#/` -> 홈
- `/#/budget-settings` -> 예산 설정
- `/#/expense-records` -> 지출 기록
- `/#/statistics` -> 분석 리포트
- `/#/calendar` -> 캘린더
- `/#/login` -> 로그인
- `/#/signup` -> 회원가입
- `/#/my-page` -> 마이페이지

비로그인 상태에서는 `/`, `/budget-settings`, `/expense-records`, `/statistics`, `/calendar`, `/my-page` 접근 시 `/login`으로 이동한다. 로그인 상태에서는 `/login`과 `/signup`에 접근해도 홈으로 되돌아간다.

## 6. 데이터 저장 방식

모든 데이터는 서버와 DB 없이 브라우저 `localStorage`에 저장한다. 데이터 접근과 저장은 `src/lib/storage.js`를 통해 관리한다.

- 계정별 예산 설정, 지출 기록, 정기지출, 알림 기록을 분리해 저장한다.
- 로그인한 계정에 따라 다른 저장 데이터가 불러와진다.
- 데모 계정에는 예산 설정과 지출 기록이 포함된 샘플 데이터가 제공된다.

## 7. 핵심 계산 로직

하루 예산 =

`(월 수입 또는 수동 예산 + 이월 금액 - 목표 저축 - 비상금 - 고정지출 - 누적 지출) / 남은 일수`

- 남은 일수는 오늘을 포함한다.
- 수동 예산 입력값이 있으면 수동 예산을 우선한다.
- 목표 설정이 켜져 있으면 목표 기간 기준 필요 저축액을 계산해 예산에 반영한다.
- 정기지출 자동 반영이 켜져 있으면 정기지출 합계를 예산 계산에 반영한다.
- 자동 반영된 정기지출은 예산 계산에서 중복 차감되지 않도록 처리한다.
- 경고 상태는 안전 / 주의 / 위험 / 초과 4단계로 구분한다.
